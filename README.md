**WELCOME TO THE AI FURRY IMAGE PACK!**

This is the first pack of images for The Voracious Galaxy and is meant as a testbed. This pack will be updated over time of course but will not be the main focus of the VG team. This is also meant to serve as an Example so YOU can make your own Image Pack for the mod, should you so desire.

**WHAT IS IN *THIS* PACK?**

This pack contain multiple species, both Anthro (Humanoid) and Feral (Qruadrupede) all featuring full bellies. No swallowing or specific entrance so let your imagination run wild on how their prey got there.
